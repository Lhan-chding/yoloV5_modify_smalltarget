# 红外小目标 YOLOv5 训练与 SS928/3403 部署要点

本仓库已经通过在 NECK 中增加 P2 分支和针对超大分辨率输入的切图推理来提升小目标召回率。【F:README.md†L1-L3】结合 SS928/3403 的 ATC 转换流程和算子支持情况，训练时可按下述建议优化模型并兼顾后续 `.om` 部署。

## 1. 数据与标签
- **保持真实红外分布**：尽量使用真实红外小目标数据，避免过度可视化增强导致分布偏移。
- **像素级标注精度**：小目标占比低时，框偏差影响更大；建议在标注前先放大 ROI 校准框。
- **类别精简**：只保留任务相关类别可减小头部参数量，便于算子映射。【F:SS928模型移植文档.txt†L9-L25】

## 2. 模型结构与超参
- **使用带 P2 检测头的配置**：沿用仓库提供的四层输出网络，保证对 160×160 特征图的覆盖。【F:README.md†L1-L3】
- **输入尺寸与步长**：训练时保持 640 或更高分辨率，但确保步长为 32 的整数倍，便于导出 ONNX 时保持静态尺寸。
- **锚框重估**：针对红外目标在 4～30 像素的尺度，重新运行 `python utils/autanchor.py --data data/<your>.yaml` 生成 P2–P5 的锚框，减少大量空锚导致的无效算子计算。
- **损失权重**：适当提高 `cls` 与 `obj` 的正样本权重（如 1.0→1.5），并在 P2 层增加小目标权重，避免训练偏向大目标。
- **数据增强可控**：保留 Mosaic/HSV 但降低强度；关闭会改变目标形态的强形变（Cutout、大尺度随机缩放），以免红外小目标消失。

## 3. 训练技巧（兼顾部署兼容性）
- **冻结与蒸馏**：可冻结 backbone 前几层或用小模型作蒸馏教师，控制参数规模，提升算子在 ATC 的映射效率。
- **避免自定义算子**：保持官方 YOLOv5 标准模块（Conv/BN/SiLU/Concat/Detect），不要加入额外激活或插件，确保 ATC 可直接识别。【F:SS928模型移植文档.txt†L26-L69】
- **导出前的静态形状**：在 `export.py` 使用固定 `--img 640 640 --opset 11`（或 ATC 支持的最低 opset），避免动态尺寸导致转换失败。
- **NMS 位置**：保留导出 ONNX 时不带 NMS（`--nms` 关闭），在 Ascend 推理端使用芯片侧算子实现，减少不匹配风险。

## 4. 转换与验证流程
- **环境准备**：按照文档在 Ubuntu 18.04 + Ascend-cann-toolkit 6.10 环境中完成 ATC 依赖安装与检查。【F:SS928模型移植文档.txt†L26-L120】
- **转换步骤**：
  1. 训练得到 `.pt`，用 `python export.py --weights best.pt --include onnx --img 640 640 --opset 11` 导出 ONNX。
  2. 在 ATC 环境使用 `atc --model=best.onnx --framework=5 --output=best --input_format=NCHW --input_shape="images:1,3,640,640" --soc_version=SS928` 生成 `.om`。
  3. 如需 3403，替换 `--soc_version=Ascend310P3`（依实际支持调整）。
- **算子校验**：转换前后用 `onnxsim`/`onnxruntime` 与 CANN 提供的 `msame` 分别跑同一批红外图片，比较 mAP 和速度，确认关键算子无退化。

## 5. 推理侧适配
- **切图推理复用**：若部署端显存/带宽有限，可沿用仓库的 3×3 网格切图策略，在上层逻辑完成裁剪与坐标还原，再将分块送入 `.om` 模型。【F:README.md†L2-L3】
- **批量与并行**：ATC 生成的 `.om` 建议保持 batch=1，避免因动态 batch 触发额外的算子分支；并在应用侧通过多路实例并行提升吞吐。
- **后处理**：在芯片侧调用 CANN 提供的 NMS/Resize/Pad，保持与训练时同样的阈值与尺度变换，避免精度漂移。

## 6. 排障建议
- **转换报错**：若 ATC 提示不支持的算子，优先检查是否启用了自定义模块或 opset 版本过高；回退到 11/12 通常更稳。
- **精度下降**：核对训练与导出时的 `img` 尺寸、anchor、NMS 阈值是否一致；对比切图与整图的差异，必要时减小切图步幅。
- **性能不足**：在不降低精度的前提下减小输入分辨率（如 512），或裁剪冗余通道/层数，保持骨干轻量化以提升 SS928/3403 的算子利用率。
